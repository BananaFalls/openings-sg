For the unemployed, by an unemployed.

I lost my job. So I started counting everyone else's.

Openings SG is what one engineer built to make sense of the job hunt. Now it's yours, free.

Who's actually hiring? What should I ask for? Is now even a good time to apply?

After the layoff, I asked myself those three questions every morning while scrolling MyCareersFuture. Nobody could answer them for me.

The answers were public, just buried across thousands of listings. So I wrote a script to count them. Within weeks I could see which roles had openings, what they really paid, and that hiring surges in the first quarter and stalls in December.

It changed how I searched. I hope it changes yours. No ads, no sign-up. I'm still looking too.

Salaries on Openings SG are what employers advertise, not final pay. Use them as a starting point. Open the dashboard →

Salaries are monthly SGD, taken as the midpoint of each posting's advertised range. "Openings" counts vacancies, so one posting can hold several. The sample dataset is generated for demonstration and is not real MyCareersFuture data. To use live data, run python3 mcf_scraper.py (daily, to build history) and load the resulting openings.json with "Load scraped data".
